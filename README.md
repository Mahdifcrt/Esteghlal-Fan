# استقلال‌فن — سایت + پنل مدیریت واقعی

## اجرا
1. Node.js نسخه 18 یا جدیدتر را نصب کنید.
2. داخل این پوشه اجرا کنید:
   npm install
3. سپس:
   npm start
4. مرورگر:
   http://localhost:3000
   پنل: http://localhost:3000/admin

## ورود پیش‌فرض
نام کاربری: admin
رمز عبور: 123456

برای سرور واقعی، حتماً ADMIN_PASS و SESSION_SECRET را به متغیر محیطی تغییر دهید.

اخبار در data/news.json ذخیره می‌شوند و تصاویر در public/uploads قرار می‌گیرند.
این نسخه آماده توسعه/استقرار است و برای محیط عمومی بهتر است HTTPS، دیتابیس واقعی، CSRF protection و محدودیت‌های امنیتی تکمیل شوند.
